# eanka.ru — Сайт студии разработки

## 🚀 Деплой на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub (например, `eanka-ru`).
2. Загрузите файлы `index.html`, `policy.html`, `robots.txt`, `sitemap.xml` в корень репозитория.
3. Перейдите в **Settings → Pages**.
4. В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`.
5. Нажмите **Save**. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/eanka-ru/`
